HORSE RACING HTML VIEWER - WINDOWS

1. Extract these files into C:\Users\PC Deals\Desktop\Speeds\
   (keep tools\sporting_life_to_html.py and build_horse_results.bat in their folders).
2. Double-click build_horse_results.bat.
3. It reads data\racing_history.sqlite and creates data\horse_results.html.
4. Open data\horse_results.html in Edge or Chrome anytime.
5. Double-click the .bat again to capture your latest saved results.

For JANUARY 2022 ONLY, run in CMD from Speeds:
  python tools\sporting_life_to_html.py --month 2022-01

For all dates (default):
  python tools\sporting_life_to_html.py

Important: The .sqlite-wal file on its own is NOT the database.
This package reads main .sqlite read-only and automatically includes committed WAL changes.
Works offline; no external website, upload or extra Python packages required.
