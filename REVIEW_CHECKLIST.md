# Real-data QA and showdown gate

Do not adopt challenger figures or revise production until the following can be demonstrated on real data.

- [ ] Exact race count and coverage through the data cutoff have been confirmed.
- [ ] Data/CSV stable during run; existing V3/V4/V12 processes finished.
- [ ] Check random samples and all clock disagreements manually against original result sources.
- [ ] Audit the number of races rejected for missing/mismatched clocks, distances and sectional joins.
- [ ] Inspect per-course/trip standard changes, especially splits of same course layouts.
- [ ] Examine section par sample sizes, winner clock matches and suspicious first/last furlong times.
- [ ] Verify missing sections do not result in fabricated segment figures.
- [ ] Compare 2yo-only, Flat Turf, AW, NHF, hurdles and chases separately.
- [ ] Create genuinely frozen historical V4 figures for an unbiased test.
- [ ] Compare identical race fields and prior-run ratings, without post-race/future features.
- [ ] Compare prediction strength and reliability, not simply percentage of figure differences.
- [ ] Out-of-time improvement survives by-season and by-course sensitivity tests and uncertainty intervals.
- [ ] Only then consider a manually approved integration in the live race cards/Supabase.
